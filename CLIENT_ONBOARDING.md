## ⏱️ 15-Minute Technical Deployment Protocol

1. Duplicate `src/config/client.config.ts` into a new client slug.
2. Fill the questionnaire responses into the configuration object.
3. Test locally with `pnpm run build`.
4. Connect Git repository to Cloudflare Pages or Vercel.
5. Set custom domain DNS records (CNAME / A records).
6. Verify live SSL and mobile WhatsApp order link.
